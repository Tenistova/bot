ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ КАСТОМНЫХ ЗВУКОВ
=============================================

Чтобы использовать свои звуки вместо программно генерируемых:

1. Поместите ваши звуковые файлы в эту папку (public/sounds/)
2. Назовите файлы следующим образом:
   - click.mp3 (или click.wav, click.ogg) - для звука "Клик"
   - pulse.mp3 (или pulse.wav, pulse.ogg) - для звука "Пульс"
   - clap.mp3 (или clap.wav, clap.ogg) - для звука "Хлопок"

3. Поддерживаемые форматы: .mp3, .wav, .ogg

4. Если файл не найден, приложение автоматически использует программно генерируемый звук

5. Звуки будут автоматически загружены при запуске приложения

ПРИМЕР:
- public/sounds/click.mp3 - ваш кастомный звук для кнопки "Клик"
- public/sounds/pulse.wav - ваш кастомный звук для кнопки "Пульс"
- public/sounds/clap.ogg - ваш кастомный звук для кнопки "Хлопок"
